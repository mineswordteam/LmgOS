A lightweight, good-looking Linux for everyday and older computers


LMG OS (also written LMGOS or Logic Mind Grid) is a free, lightweight Linux distribution based on Debian 13 with an XFCE desktop, made by Minesword Team (mineswordteam). It aims to be a low-resource, beautiful alternative for people looking for a light Linux with a modern neon-blue look: zram and earlyoom keep low-RAM computers responsive, it runs on 2 GB of RAM, includes a Calamares installer, a custom control panel, a USB guard, Wine for Windows apps, wide hardware support and Persian and English interfaces. If you are searching for a lightweight Linux for old PCs, a low-memory Linux desktop, a good-looking Linux distro, a Windows-like Linux or an Iranian Linux operating system, LMG OS is built for that. Free download: github.com/mineswordteam/lmgos_download.


لینوکس سبک، کم‌مصرف و خوش‌ظاهر برای کامپیوترهای معمولی و قدیمی


ال‌ام‌جی او اس (LMG OS یا LMGOS) یک سیستم‌عامل لینوکس رایگان، سبک و کم‌مصرف بر پایه‌ی دبیان ۱۳ با محیط XFCE است که توسط تیم ماین‌سورد (Minesword Team) ساخته شده. اگر دنبال «بهترین لینوکس برای سیستم ضعیف»، «لینوکس سبک و خوش‌ظاهر»، «لینوکس کم‌مصرف برای لپ‌تاپ قدیمی»، «لینوکس شبیه ویندوز» یا «سیستم‌عامل ایرانی» هستید، ال‌ام‌جی او اس برای همین ساخته شده: ظاهر مدرن آبی نئونی، مدیریت رم با zram و earlyoom، اجرا با ۲ گیگابایت رم، نصب‌کننده‌ی ساده، کنترل پنل اختصاصی، اجرای برنامه‌های ویندوز با Wine و رابط فارسی و انگلیسی. دانلود رایگان: github.com/mineswordteam/lmgos_download.

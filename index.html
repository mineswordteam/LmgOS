New in LMG OS 1.1

تازه‌های LMG OS 1.1

A big update: a Persian system, upgrades that keep your data, a Package Manager and more.

یک به‌روزرسانی بزرگ: سیستم فارسی، ارتقا بدون از دست رفتن داده، مدیر بسته و بیشتر.

Persian for the whole system

فارسی برای کل سیستم

One tap on the taskbar language button switches the desktop, menus, apps and keyboard to Persian, without mixing Persian and English words in a sentence.

با یک کلیک روی دکمه‌ی زبان نوار وظیفه، دسکتاپ، منوها، برنامه‌ها و کیبورد فارسی می‌شوند، بدون اینکه کلمه‌های فارسی و انگلیسی وسط جمله قاطی شوند.

Upgrade without losing data

ارتقا بدون از دست دادن داده

The installer finds an older LMG OS and upgrades it while keeping your files, settings and programs. You can also upgrade from the Control Panel.

نصب‌کننده LMG OS قدیمی را پیدا می‌کند و بدون حذف فایل‌ها، تنظیمات و برنامه‌ها آن را ارتقا می‌دهد. از پنل کنترل هم می‌شود ارتقا داد.

Graphical Package Manager

مدیر بسته‌ی گرافیکی

Search, install and remove programs with a click. The packages that make up LMG OS are locked, so you cannot remove them by mistake.

برنامه‌ها را با یک کلیک جست‌وجو، نصب و حذف کنید. بسته‌های اصلی LMG OS قفل هستند و به‌اشتباه حذف نمی‌شوند.

A lightweight, good-looking Linux for everyday and older computers

Logic Mind Grid OS (LMG OS, also written LMGOS) is a free, lightweight Linux distribution based on Debian 13 with an XFCE desktop, made by Minesword Team (mineswordteam). It is a low-resource, beautiful alternative for people looking for a light Linux with a modern neon-blue look: zram and earlyoom keep low-RAM computers responsive, it runs on 2 GB of RAM, and it includes a Calamares installer, a custom control panel, a USB guard, Wine for Windows apps, wide hardware support and Persian and English interfaces. If you are searching for a lightweight Linux for old PCs, a low-memory Linux desktop, a good-looking Linux distro, a Windows-like Linux or an Iranian Linux operating system, LMG OS is built for that.

لینوکس سبک، کم‌مصرف و خوش‌ظاهر برای کامپیوترهای معمولی و قدیمی

ال‌ام‌جی او اس (LMG OS یا LMGOS) یک سیستم‌عامل لینوکس رایگان، سبک و کم‌مصرف بر پایه‌ی دبیان ۱۳ با محیط XFCE است که توسط تیم ماین‌سورد (Minesword Team) ساخته شده. اگر دنبال «بهترین لینوکس برای سیستم ضعیف»، «لینوکس سبک و خوش‌ظاهر»، «لینوکس کم‌مصرف برای لپ‌تاپ قدیمی»، «لینوکس شبیه ویندوز» یا «سیستم‌عامل ایرانی» هستید، ال‌ام‌جی او اس برای همین ساخته شده: ظاهر مدرن آبی نئونی، مدیریت رم با zram و earlyoom، اجرا با ۲ گیگابایت رم، نصب‌کننده‌ی ساده، پنل کنترل اختصاصی، اجرای برنامه‌های ویندوز با Wine و رابط فارسی و انگلیسی.

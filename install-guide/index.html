Install guide

راهنمای نصب

From the download to a working desktop in a few minutes.

از دانلود تا دسکتاپ آماده، در چند دقیقه.

1. Prepare

۱. آماده‌سازی

Download and checkدانلود و بررسی

Download the ISO and the SHA-256 file from the download page and check them. The result must match.

فایل ISO و SHA-256 را از صفحه‌ی دانلود بگیرید و بررسی کنید. باید یکی باشند.

Back up your dataپشتیبان بگیرید

Installing can erase data. Save your files before you choose a disk.

نصب ممکن است اطلاعات را پاک کند. پیش از انتخاب دیسک فایل‌هایتان را ذخیره کنید.

Write it to a USB stickنوشتن روی فلش

Use Rufus (choose DD Image mode), balenaEtcher or dd. This erases the stick.

از Rufus (حالت DD Image را انتخاب کنید)، balenaEtcher یا dd استفاده کنید. فلش پاک می‌شود.

2. Boot

۲. بوت

Open the boot menuمنوی بوت

Restart and press F12, F10, Esc or F2 (it depends on your computer). Choose the USB stick.

ریستارت کنید و F12، F10، Esc یا F2 را بزنید (به کامپیوتر بستگی دارد). فلش را انتخاب کنید.

Choose LMG OS LiveLMG OS Live را انتخاب کنید

If the screen stays black, restart and choose the safe graphics entry.

اگر صفحه سیاه ماند، دوباره بوت کنید و گزینه‌ی safe graphics را بزنید.

3. Install or upgrade

۳. نصب یا ارتقا

Start the installerنصب‌کننده را اجرا کنید

Open Install LMG OS on the desktop and follow the steps. You choose your own password.

Install LMG OS را روی دسکتاپ باز کنید و مراحل را بروید. رمز را خودتان انتخاب می‌کنید.

Upgrading from 1.0?ارتقا از 1.0؟

When the installer finds LMG OS 1.0 it offers Upgrade: your files, settings and programs are kept. Choose Install instead for a clean install.

وقتی نصب‌کننده LMG OS 1.0 را پیدا کرد Upgrade را پیشنهاد می‌دهد: فایل‌ها، تنظیمات و برنامه‌هایتان می‌مانند. برای نصب تمیز Install را بزنید.

Restart and enjoyریستارت و لذت ببرید

Remove the USB stick when asked. The first start shows a short Welcome and tutorial.

وقتی خواست فلش را بردارید. اولین بار یک خوش‌آمد و آموزش کوتاه نشان داده می‌شود.

Problems?

مشکل دارید؟

The USB stick shows a tiny size in Windows

فلش در ویندوز حجم خیلی کم نشان می‌دهد

That is normal after writing an ISO. To use the stick again, open Disk Management, delete its volumes and create a new FAT32 volume, or use Rufus with “Non bootable”.

بعد از نوشتن ISO طبیعی است. برای استفاده‌ی دوباره، در Disk Management بخش‌های فلش را حذف کنید و یک پارتیشن FAT32 جدید بسازید، یا Rufus را با «Non bootable» بزنید.

The installer cannot erase a partition

نصب‌کننده نمی‌تواند پارتیشن را پاک کند

Make sure the partition is not mounted (unmount it in the file manager or with umount) and try again.

مطمئن شوید پارتیشن mount نشده باشد (در مدیر فایل یا با umount جدا کنید) و دوباره امتحان کنید.

Black screen or no boot

صفحه‌ی سیاه یا بوت نشدن

Use the safe graphics entry. If it still fails, email us your computer model and a photo.

گزینه‌ی safe graphics را بزنید. اگر باز هم نشد، مدل کامپیوتر و یک عکس برایمان ایمیل کنید.

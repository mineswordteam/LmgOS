Next stepsمراحل بعد

Write it to a USB stickنوشتن روی فلش

Use Rufus (DD Image mode), balenaEtcher or dd. This erases the stick.

از Rufus (حالت DD Image)، balenaEtcher یا dd استفاده کنید. فلش پاک می‌شود.

Boot from itبوت از روی فلش

Restart and open the boot menu (F12, F10, Esc or F2). Choose LMG OS Live.

ریستارت کنید و منوی بوت را باز کنید (F12، F10، Esc یا F2). LMG OS Live را انتخاب کنید.

Try it or install itامتحان یا نصب

Start Install LMG OS on the desktop. If you have LMG OS 1.0, choose Upgrade to keep your data.

Install LMG OS را روی دسکتاپ اجرا کنید. اگر LMG OS 1.0 دارید، برای حفظ اطلاعات Upgrade را بزنید.

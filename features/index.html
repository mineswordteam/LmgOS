Features

ویژگی‌ها

Everything LMG OS gives you, in one light system.

هرچه LMG OS به شما می‌دهد، در یک سیستم سبک.

New in 1.2

تازه در 1.2

🛡️

Ultimate Security

امنیت نهایی

Alt+F3 cuts every connection, unloads network, camera and USB-storage drivers and locks the computer down. Alt+F3 again turns it off.

Alt+F3 همهٔ ارتباط‌ها را قطع می‌کند، درایورهای شبکه، دوربین و USB را خارج و کامپیوتر را قفل می‌کند. دوباره Alt+F3 آن را خاموش می‌کند.

🔌

USB Guard

نگهبان USB

Drives and USB devices are checked before you can use them: fake keyboards (BadUSB), file system errors and typical USB malware.

فلش و دستگاه‌های USB پیش از استفاده بررسی می‌شوند: کیبورد جعلی (BadUSB)، خطای سیستم فایل و بدافزارهای رایج USB.

🎮

Windows gaming

بازی ویندوزی

DXVK set up automatically, Wine drive mapping, FPS display and a Windows Gaming card.

DXVK خودکار، نگاشت درایوهای Wine، نمایش FPS و کارت بازی ویندوزی.

📱

LMG Connector file transfer

انتقال فایل در LMG Connector

Control the computer from your phone and send files and text both ways. New three-column window.

کنترل کامپیوتر از گوشی و ارسال فایل و متن در دو جهت. پنجرهٔ جدید سه‌ستونه.

🧩

LMG Driver

LMG Driver

Finds drivers, firmware and gaming tools for this computer online and installs them after a restart.

درایور، فریمور و ابزارهای بازی این کامپیوتر را آنلاین پیدا و بعد از ریستارت نصب می‌کند.

✨

New look

ظاهر جدید

New neon window frame, a snake-style logo shutdown animation and a sidebar that fits your screen.

قاب جدید نئونی پنجره‌ها، انیمیشن خاموشی لوگو مثل مار و سایدبار هم‌اندازهٔ صفحه.
